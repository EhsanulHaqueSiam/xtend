# Keys and the command palette

## Command palette

`⌘K` opens the palette over everything, x.com included. Type a command, `@handle` or a search:

- a screen, or once you type, a section (Compose, Plan: Slots, …)
- X's pages (Home, Notifications, Messages, Bookmarks, Explore, Follow)
- **Schedule this**: a new draft in Compose
- `@handle`: report on the handle in Scores, or open the profile on X
- run a Leads agent by name, with its price beside it
- search the Library: the query lands in Library search, and its priced **Search** runs it

## Keys in the app

| key   | does                                   |
| ----- | -------------------------------------- |
| `⌘K`  | command palette                        |
| `⌘\`  | dock or hide x.com beside the tool     |
| `⌘F`  | find in x.com                          |
| `c`   | Compose                                |
| `p`   | Plan                                   |
| `a`   | Analyze                                |
| `e`   | Engage                                 |
| `l`   | Library                                |
| `s`   | Library, with Search X focused         |
| `x`   | x.com full size                        |
| `Esc` | close the detail column or the palette |

Single letters only act when no text field has focus. On Linux, `Ctrl` stands in for `⌘`.

In Automate's Needs you, a focused card takes `a` to approve and `s` to skip.

## Keys in x.com

While x.com has focus its own keys stay X's (`j`, `k`, `l`, `r`). The chords above still reach
the app, and these are added:

| key            | does                          |
| -------------- | ----------------------------- |
| `⌘[` `⌘]`      | back, forward                 |
| `⌘=` `⌘-` `⌘0` | zoom in, out, reset           |
| `⌥O`           | hide or show the metrics rows |

## Notifications

New mentions, new leads, automation notify actions and ask-first requests become OS
notifications. The desktop has the permission; a browser asks once.
