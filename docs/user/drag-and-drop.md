# Drag and drop

## A post onto a tool

Drag a post, from X in the middle of the window, from a browser tab, from a row in Seen or from
a Library card, onto a row in the sidebar. While you drag, the rows that take a post show what
they would do and the rest fade:

| drop on | does                             |
| ------- | -------------------------------- |
| Compose | starts a draft quoting the post  |
| Library | saves the post                   |
| Leads   | adds the author to People        |
| Scores  | adds the author to the watchlist |

One toast confirms it, with Undo where the service can reverse it. A post your session has
not seen yet cannot be saved from a drop; the toast says so. Open it on X first.

Drops never call X. They read the post's URL and what your session already observed.

## Inside a tool

| drag                                   | onto                                    | does                                      |
| -------------------------------------- | --------------------------------------- | ----------------------------------------- |
| a card on Compose's drafts board       | another column                          | moves it on (see [Compose](./compose.md)) |
| a Ready to post draft or a queued post | an open slot or an hour on Plan's ruler | schedules it then                         |
| a Library card                         | a collection in the Collections rail    | files the post there                      |
| a person on Leads' Stages board        | another stage                           | moves them to that stage                  |

Moves on the drafts board and the stages board come with a toast and Undo.
