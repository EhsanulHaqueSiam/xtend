# Keyboard

`⌘` is `Ctrl` on Linux.

| keys           | does                                      |
| -------------- | ----------------------------------------- |
| `⌘K`           | command palette: every screen and X page  |
| `⌘\`           | show or hide the X panel                  |
| `⌘F`           | find in x.com                             |
| `⌘[` `⌘]`      | back and forward in x.com                 |
| `⌘=` `⌘-` `⌘0` | zoom x.com                                |
| `⌥O`           | show or hide Xtend's rows under X's posts |

Outside a text field, one letter opens a screen: `c` Compose, `p` Plan, `a` Analyze, `e`
Engage, `l` Library, `s` Library search, `r` reply, `x` X. Inside x.com, X's own single-letter
shortcuts keep working.
