# Settings and accounts

- **X account**: your handle. Taken from your X session when empty. Scores, Analyze and
  Engage are about it.
- **treg and budget**: your treg token and the monthly budget in USD. Paid calls stop before
  the month's spend would pass the budget. Daily Library jobs, off by default, fetch picks,
  detect hook patterns and write three ready drafts each morning at their listed prices.
- **Time and voice**: the time zone for slots, the calendar and best hours; voice notes, one
  paragraph on what you post about and how you sound, which the assistant writes in; keywords,
  which Library, Engage and Leads search by default.
- **X session**: post media through the x.com session instead of the API (off by default), and
  Clean X.
- **Spend**: today, this month and the budget.
- **Service**: which service this window talks to, how it was started, its version and data
  directory.
- **Accounts**: every X handle you connected. Each has its own X login, data and schedule.
  Switching rebuilds the window on the other account; it is refused while a post is going out.
- **Remote service**: open this service from another browser with `?token=` and the token
  from `auth-token` in its data directory.
