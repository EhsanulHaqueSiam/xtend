# Using Xtend

Xtend is a desktop app for growing on X. X runs inside it as your own logged-in session, and a
local service on your machine adds the tools: a composer with a queue, a library of posts that
did well, engagement targets, lead lists, automations, analytics and account scores. Free lanes
come first; anything that costs money shows its price before it runs and stays inside your budget.
